### ObsidianGitManage

A simple yet extremely effective plugin that connects your Obsidian vault to a GitHub repository, allowing fast upload and download of large amounts of data through the traditional GitHub **Pull & Push** workflow.

Connect your repository, enable the plugin, and you're ready to go — with features such as automatic synchronization.
